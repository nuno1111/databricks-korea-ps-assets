# Demos

고객 미팅이나 PoC에서 활용할 수 있는 데모 노트북 모음입니다. 가상 데이터로 시나리오를 시뮬레이션해 Databricks 기능을 시연하기 위한 자산을 정리합니다.

|--------|------|------|
| salesforce-lakeflow | Salesforce CRM → Databricks Lakeflow Connect 데모 | 🚧 TBD |

## 자산 추가 가이드

데모 자산은 다음을 포함합니다.
- 실행 가능한 노트북 (Python/SQL)
- 가상 데이터 생성 스크립트 (실제 고객 데이터 금지)
- `README.md` (데모 시나리오, 실행 순서, 핵심 메시지)
- (선택) 발표용 스피커 노트 또는 슬라이드 링크
